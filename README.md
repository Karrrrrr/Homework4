Описание проекта:
Мобильное приложение для отслеживания подписок на платные сервисы

Инструкции по запуску:
	На эмуляторе:
		1. Откройте проект в Visual Studio
		2. В раскрывающемся меню запуска выберите "Эмуляторы Android Emulator"
		3. Скачайте любой эмулятор
		4. Запустите проект на эмуляторе
	На собственном устройстве:
		1. Переместить apk файл на устройство
		2. Запустить apk, установить приложение
